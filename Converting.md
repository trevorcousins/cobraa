# Guide for Converting BAM Files to MHS Files for MSMC2 Analysis

MSMC2 is a widely used tool for analyzing population history dynamics, requiring input files in the multihetsep (MHS) format. This guide details the process of converting BAM files to MHS files for MSMC2 analysis.

---

## **Prerequisites**

### **Required Tools**

- `samtools`
- `bcftools`
- `msmc-tools` (includes the scripts `bamCaller.py` and `generate_multihetsep.py`)


### **Required Files**

- Sorted BAM file
- Reference genome sequence (FASTA format)
- Mappability mask files (BED format) to mark reliable genomic regions

---

## **Installation**

### **Installing Tools**

```bash
# Install samtools and bcftools (Debian/Ubuntu)
sudo apt-get install samtools bcftools

# Install samtools and bcftools (CentOS/RedHat)
sudo yum install samtools bcftools

# Download msmc-tools
git clone https://github.com/stschiff/msmc-tools.git
```

---

## **Conversion Steps**

### **Step 1: Sort and Index the BAM File**

If your BAM file is already sorted, skip the sorting step and proceed to indexing.

```bash
# Sort the BAM file
samtools sort input.bam -o sorted_input.bam

# Create an index
samtools index sorted_input.bam
```

---

### **Step 2: Calculate Mean Coverage**

The `bamCaller.py` script requires the mean coverage as a parameter. Calculate it using:

```bash
# Example for chromosome 1
samtools depth -r chr1 sorted_input.bam | awk '{sum += $3} END {print sum / NR}'
```

---

### **Step 3: Convert BAM to VCF and BED Files**

Process each chromosome individually:

```bash
# Process chromosome 1
bcftools mpileup -q 20 -Q 20 -C 50 -r chr1 -f reference.fa sorted_input.bam | \
bcftools call -c -V indels | \
/path/to/msmc-tools/bamCaller.py &lt;MEAN_COVERAGE&gt; chr1.bed.gz | \
gzip -c &gt; chr1.vcf.gz
```

**Parameter Descriptions**:

- `-q 20`: Minimum mapping quality
- `-Q 20`: Minimum base quality
- `-C 50`: Filter parameter for mismapped reads
- `-r chr1`: Target chromosome
- `-f reference.fa`: Path to the reference genome
- `&lt;MEAN_COVERAGE&gt;`: Replace with the value calculated in Step 2.

---

### **Step 4: Generate MHS Files**

For each chromosome, generate the MHS file using:

```bash
python /path/to/msmc-tools/generate_multihetsep.py \
  --mask=chr1.bed.gz \
  --mask=/path/to/mappability/masks/chr1.bed \
  chr1.vcf.gz &gt; chr1.mhs
```

**Parameter Descriptions**:

- `--mask=chr1.bed.gz`: Coverage mask generated by `bamCaller.py`
- `--mask=/path/to/mappability/masks/chr1.bed`: Genome-wide mappability mask

---

## **Automated Processing for All Chromosomes**

Create a Bash script (`bam2mhs.sh`) to process all chromosomes:

```bash
#!/bin/bash

# Set variables
BAM_FILE="sorted_input.bam"
REFERENCE_FA="/path/to/reference.fa"
MSMC_TOOLS_DIR="/path/to/msmc-tools"
MAPPABILITY_MASKS_DIR="/path/to/mappability/masks"
MEAN_COV=30  # Replace with your calculated mean coverage

# Process each chromosome
for CHROM in {1..22}; do
  echo "Processing chromosome $CHROM..."
  
  # Generate VCF and BED files
  bcftools mpileup -q 20 -Q 20 -C 50 -r chr$CHROM -f $REFERENCE_FA $BAM_FILE | \
  bcftools call -c -V indels | \
  $MSMC_TOOLS_DIR/bamCaller.py $MEAN_COV chr$CHROM.bed.gz | \
  gzip -c &gt; chr$CHROM.vcf.gz
  
  # Generate MHS file
  python $MSMC_TOOLS_DIR/generate_multihetsep.py \
    --mask=chr$CHROM.bed.gz \
    --mask=$MAPPABILITY_MASKS_DIR/chr$CHROM.bed \
    chr$CHROM.vcf.gz &gt; chr$CHROM.mhs
done

echo "All done!"
```

**Run the script**:

```bash
chmod +x bam2mhs.sh
./bam2mhs.sh
```

## **Key Considerations**

1. **Large Genomes**:
    - Processing may take hours or days. Use high-performance computing (HPC) environments for efficiency.
    - Use `screen` or `tmux` to maintain long-running sessions.
2. **Mappability Masks**:
    - For human genomes, download precomputed masks from public databases (e.g., UCSC).
    - For non-model species, generate masks using tools like `SNPable`.
3. **Coverage Threshold**:
    - Optimize the mean coverage threshold in `bamCaller.py` to balance sensitivity and specificity.
4. **Parallelization**:
    - Use workflow managers like `Snakemake` for multi-sample processing.

---

## **Running MSMC2**

After generating MHS files, execute MSMC2:

```bash
msmc2 -o output_prefix chr1.mhs chr2.mhs ... chr22.mhs
```

This generates output files (e.g., `output_prefix.final.txt`) that can be visualized to infer historical population size changes.

---

## **Troubleshooting**

- **File Corruption**: Validate BAM integrity with `samtools quickcheck`.
- **Memory Issues**: Process chromosomes individually to reduce memory usage.
- **Permission Errors**: Ensure write access to output directories.

By following these steps, you can efficiently convert BAM files to MHS format and perform population history analysis using MSMC2.
